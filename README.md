# Redmine 협업 툴

Windows용 데스크톱 앱으로 Redmine 이슈를 불러와 현재 업무를 등록·완료 처리하고, 완료 시 Redmine 댓글 및 앱 알림으로 배정자에게 알립니다.

## 요구 사항

- Node.js 18+
- Redmine 서버 (REST API 사용)
- Redmine 사용자 API 키 (관리자 → 사용자 → API 키)

## 설치 및 실행

```bash
cd redmine-collab-tool
npm install
npm run dev
```

개발 시 Vite와 Electron을 각각 실행하려면:

```bash
# 터미널 1
npm run dev:vite

# 터미널 2 (Vite가 뜬 뒤)
npm run dev:electron
```

## 빌드

```bash
npm run build
```

실행 파일은 `release/` 폴더에 생성됩니다.

## 협업 서버 (여러 PC에서 같은 데이터·알림 공유)

여러 PC에서 같은 사용자·업무·알림을 쓰려면 협업 서버를 한 대 띄운 뒤, 각 PC의 앱 설정에서 **협업 서버 URL**을 입력하세요.

```bash
# 프로젝트 루트에서 (서버는 한 대만 실행)
npm run server
```

서버는 기본 포트 3000에서 동작합니다. 같은 네트워크의 다른 PC에서는 `http://서버PC의IP:3000` (예: `http://192.168.0.10:3000`)을 설정에 입력하면 됩니다. 관리자 로그인 후 **설정** 탭 → **협업 서버 URL**에 입력 후 저장하세요.

## 설정

1. **데모 모드**: 설정에서 "데모 모드 (실제 Redmine 없이 샘플 데이터로 사용)"를 켜면 API 키 없이 샘플 이슈로 동작을 확인할 수 있습니다. 실제 Redmine을 쓰려면 데모 모드를 끄고 아래 항목을 입력하세요.
2. **Redmine URL**, **API 키**: 설정 탭에서 입력 후 저장.
3. **배정자 커스텀 필드 ID**: Redmine에서 이슈에 "업무 배정자(상위 담당자)"를 저장하는 커스텀 필드의 ID. (관리자 → 커스텀 필드에서 확인)
4. **완료 상태 ID**: 이슈를 완료로 바꿀 때 사용할 Redmine 상태 ID (기본 3).
5. **협업 서버 URL**: 여러 PC에서 같은 데이터를 쓰려면 위처럼 서버를 띄운 뒤, 여기에 `http://서버IP:3000` 형식으로 입력하세요. 비우면 로컬만 사용합니다.

## 사용 방법

- **내 업무**: Redmine에서 나에게 할당된 이슈 목록을 불러옵니다. "진행으로 설정"으로 현재 업무를 지정하고, "완료 처리"로 상태를 완료로 변경하며 Redmine에 댓글을 남깁니다.
- **완료 알림**: 배정자로 지정된 이슈 중 최근 완료된 목록을 보여줍니다. 주기적으로 새 완료 이슈가 있으면 알림이 표시됩니다.
- Redmine 쪽 알림(이메일 등)은 Redmine 설정에 따라 배정자에게 전달됩니다. (이슈에 댓글이 추가되면 Redmine에서 이메일 발송 가능)
- 이 앱에서 직접 이메일을 보내려면 설정에 SMTP 정보를 추가하는 확장이 필요합니다.
